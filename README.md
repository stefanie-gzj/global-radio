# 📻 Free Global Radio

免费收听全球电台的网页播放器。数据来自公开的 [radio-browser.info](https://www.radio-browser.info/) 数据库。

**网址：** https://global-radio-pi.vercel.app

## 功能

- 按热度浏览全球电台，支持流派筛选（流行、摇滚、爵士、古典、电子、新闻等）
- 按名字搜索电台
- 按音质筛选（64k / 128k / 192k 以上）
- 收藏喜欢的电台，保存在本机浏览器里
- 中英文界面切换
- 音量归一化：在电台允许的情况下自动压平响度差异

## 列表是怎么清洗的

radio-browser 是个开放数据库，同一个电台经常被登记好几遍，也有不少已经停播的地址。所以在显示之前做了三件事：

1. **只保留数据库最近巡检确认可用的**（`lastcheckok = 1`）
2. **两道去重**：先按流地址去重（同一个流挂着不同名字），再按台名 + 国家去重（同一个台重复登记）
3. **本机记忆失效电台**：点开连不上的台会被记下来，自动置灰并沉到列表底部，播放键变成「重试」。记录只保留 3 天——电台经常只是临时抽风，过几天可能自己就好了

另外 API 服务器配了四个镜像，一台连不上会自动换下一台。

## 本地运行

需要 Node.js 18 以上。

```bash
npm install     # 安装依赖
npm run dev     # 本地开发，浏览器打开提示的地址
npm run build   # 打包
```

## 技术栈

React + TypeScript + Vite，部署在 Vercel。推送到 `main` 分支会自动重新部署。

## 目录结构

```
src/
  components/   界面组件（电台卡片、列表、播放条、搜索、筛选）
  hooks/        播放器、收藏、失效电台记录
  services/     radio-browser API 调用与数据清洗
  context/      中英文切换
  i18n/         文案
  types/        类型定义
```
